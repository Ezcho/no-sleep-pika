# Mac에 pika 설치하기: PKG와 보조 서비스

응용 프로그램에 설치하고, 메뉴 막대에서 사용하세요.

- 01

**pika**Session OFFQuit · 종료

## 기존 pika 종료

Session을 OFF로 바꾼 뒤 메뉴 막대의 pika → 종료를 선택하세요. 창의 ×를 누르면 앱은 계속 실행 중입니다.

- 02

PKG→

**pika**App + Helper

## PKG 설치

다운로드한 pika PKG를 열고 macOS 설치 프로그램에서 계속 진행해 관리자 승인을 완료하세요. 앱과 보조 서비스가 함께 설치됩니다.

- 03

pika→

● ● ●**pika**Session Monitor

## pika 실행

응용 프로그램에서 pika를 여세요. 제어창이 전면에 나타납니다. 보조 서비스 연결을 확인하고 Session ON → 덮개 닫기 순서로 사용하세요.

## 설치 전이나 업데이트 후, macOS가 막았나요?

macOS가 앱 실행을 허용하기 전에는 pika가 안내창을 띄울 수 없습니다. 이 페이지를 열어 둔 채 진행하세요. 업데이트 후 다시 승인을 요청할 수도 있습니다.

- 다운로드한 pika PKG를 먼저 한 번 여세요. 설치는 끝났는데 앱이 차단됐다면 응용 프로그램의 pika를 먼저 여세요.

- 개발자를 확인할 수 없거나 Apple이 검증할 수 없다는 경고라면, 시스템 설정 → 개인정보 보호 및 보안으로 이동하세요. 아래쪽 보안 영역에서 방금 연 파일 이름을 확인하세요.

- 그 파일과 다운로드 출처를 신뢰할 때만 ‘그래도 열기’를 선택하세요. macOS가 요청하면 인증하고, 다시 나타나는 경고에서 ‘열기’를 확인하세요.

- 해당 항목이 없다면 같은 파일을 한 번 더 열어 본 뒤 돌아오세요. 회사·학교에서 관리하는 Mac은 관리자 확인이 필요할 수 있습니다.

PKG나 pika 실행 시 개발자를 확인하거나 앱을 검증할 수 없다는 경고가 나오면, 출처를 신뢰할 때만 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기를 선택하세요. 현재 빌드는 Developer ID 서명·공증이 없습니다.

“컴퓨터를 손상시킵니다”, 악성 소프트웨어 또는 인증 취소 경고는 우회하지 마세요. “손상되었습니다”라면 진행을 멈추고 받은 파일을 삭제한 뒤 공식 홈페이지에서 다시 받으세요. 반복되면 우회하지 말고 문의해 주세요.

[Apple 공식 앱 실행 안내 ↗](https://support.apple.com/ko-kr/102445)

## 앱은 열렸는데 Session이 시작되지 않나요?

앱 실행 허용과 보조 서비스 설치는 별개입니다. “그래도 열기”만으로 보조 서비스 연결 문제가 해결되는 것은 아닙니다.

- 홈페이지에서 최신 pika 통합 PKG를 받으세요.

- Session을 OFF로 바꾸고 메뉴 막대에서 pika를 종료한 뒤 PKG를 실행하세요.

- 설치 완료 후 pika를 다시 여세요. 다시 실패하면 설치 프로그램 → 윈도우 → 설치 프로그램 로그에서 이유를 확인할 수 있습니다.

보조 서비스는 관리자 권한이 필요한 전원 제어를 담당합니다. 설치 내용을 확인한 뒤 승인하세요. 설치 파일도 macOS에 차단되면 출처를 신뢰할 때만 같은 “그래도 열기” 절차를 사용하세요.

준비되면: Session ON → 맥북 덮개 닫기.
