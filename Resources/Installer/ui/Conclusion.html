설치를 완료했습니다 · Installed

응용 프로그램 폴더에서 pika를 여세요.
Open pika from Applications.

보조 서비스가 연결되면 Session ON → 덮개 닫기 순서로 사용하세요. 창을 닫아도 메뉴 막대에서 실행됩니다.
Once the helper is connected, turn Session ON and close the lid. Closing the window keeps pika running in the menu bar.

앱이 열리지 않나요? · App blocked?

pika를 먼저 한 번 연 뒤, 시스템 설정 → 개인정보 보호 및 보안에서 파일 이름을 확인하세요. 개발자 확인 경고라면 출처를 신뢰할 때만 ‘그래도 열기’ → macOS 인증 → ‘열기’를 진행하세요.
Try opening pika once. For an unidentified-developer warning, find that file in System Settings → Privacy & Security. Only if you trust its source, choose Open Anyway, authenticate if asked, then confirm Open.

손상·악성 소프트웨어·인증 취소 경고는 우회하지 마세요.
Do not bypass damaged-file, malware or revoked-authorization warnings.
